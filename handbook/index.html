助教工作手册

按“开课 → 上课 → 结课”整理，便于现场快速查找。

本页依据公开共享的原助教手册重新整理，不含账号、密码、学员名单或其他个人信息。课表、系统步骤和设备要求如有变化，以当前通知、授权范围及设备操作规程为准。
01

开课前准备

课程报备

  1. 从负责人取得当期课表、班级、人数及场地信息。
  2. 在培训系统的课程管理中新增课程，核对日期、时段、工种、教室和人数。
  3. 检查与其他单位课程是否冲突；安全实训、体验和理论课按当期课表安排。
  4. 提交前再次核对人数。超过系统可修改时间后，按现行流程联系系统管理人员处理。

报名资料

  1. 进入当期课程的报名管理，生成报名二维码。
  2. 在二维码页面清楚标注班级或工种。
  3. 将二维码更新到当期报名流程和报名指引中，保存到当期资料目录。
  4. 把报名信息交给招生或对应负责人。

现场与设备

  1. 确认教室、走廊通风和照明，摆放必要的指引牌。
  2. 测试电脑、大屏、音响和麦克风；检查电池、饮水和纸杯。
  3. 准备课表、学员群二维码、签到设备、反光衣及当期使用的表单。
  4. 有外聘老师时，提前准备饮水和教学资料。
不要在网页、公开文件或群公告中写入系统账号、密码。需要登录时向授权管理人员取得当期可用方式。
02

第一天

7:30–8:00

入场、报名与刷脸签到

一楼引导学员到教室；按单位和培训天数核对。教室内提示穿反光衣、按工种就座，完成报名核验和二次点名后组织刷脸签到。签到结束后汇总到场人数，导出名单并制作分组表、签到表和后续考核表。

上午课程

早班会与理论课

提前打开课件，开课前召回学员并说明课堂纪律。课程中巡场、协助互动、按要求完成影像留痕；上午结束后关闭电脑、灯、空调和大屏。

13:15–13:30

中午签到

提前准备下午课件，分班组织签到。发现未到人员时及时联系，并按内部流程记录姓名、单位和原因。

下午课程

工种理论与工种实训

理论课沿用上午课堂流程。工种实训前准备评分表、参考表、组牌和袖章，按分组整队并清点人数；每组完成操作、评分、成果合影和结束报告，全部完成后进行总结和场地清理。

当天结束

晚班会、签退与关场

完成当日总结和刷脸签退，确认所有学员完成签退。整理桌椅和垃圾，关闭设备与电源，回收麦克风电池，检查门窗。

03

第二天

7:30–8:10

早签到与实训准备

按第一天签到流程执行；提前打开安全体验与实训课件，根据课表准备讲解设备和扩音设备。

8:10–11:10

安全体验与安全实训

按分组表发放组牌和袖章，整队核对人数后进入实训区域。依次完成安全帽、安全带、剪叉式升降平台、灭火器、劳保用品、挤压伤害、有限空间、洞口坠落、触电、安全标识和机械伤害等教学或体验项目，具体项目以当期课表为准。

13:15–16:40

签到与事故案例课程

组织午间签到；两段事故案例课程沿用理论课标准流程，提前开课件、维持课堂秩序并按要求留痕。

16:45–17:30

测评与理论考试

准备问卷、考试指引、考试二维码和纸质备用试卷。确认所有学员进入考试，维护考场纪律并完成留痕。考试结束后按当期规则确认优秀学员，更新颁奖内容并完成关场。

设备与体验安全：所有实训和体验设备由具备相应权限、熟悉设备规程的人员开启和操作；每次转场先整队清点，使用前做安全交底，结束后断电、归位、还钥匙并完成场地清理。
04

签到与现场留痕

现场拍摄

  • “6+1”：同一课程按要求拍摄 6 张不同角度的横屏广角照片和 1 段不少于 1 分钟的视频，画面应覆盖课程、讲师和参训人员。
  • 工种实训按组拍摄操作过程、组牌、完成报告和成果合影；转场及总结按当期要求补齐影像。
  • 拍摄后立即检查清晰度、构图和现场状态，避免油污镜头、遮挡、人员缺失或明显不符合课堂要求的画面。
  • 当日课程照片应在当日整理并上传到当期资料目录。

后台上传

上传项内容
实操照片安全实训、安全体验、工种实训等照片，按系统要求分类压缩。
理论视频理论课程视频，时长按当前系统要求准备。
课堂照片按后台要求选择课堂视角；后台上传数量与现场“6+1”留痕分别核对。
影像资料可能包含个人信息，只存放在批准的内部目录或系统中，不放入本公开网页和 GitHub 仓库。
05

结课与系统资料

资料整理

  • 收集当期课堂、实训、体验、考试和颁奖影像，按课程与类别归档。
  • 导出两天签到人员信息，与手签、课表和分组表一起保存。
  • 整理工种实训评分、理论考试成绩和成绩汇总表。

系统结课

  • 在课程管理中确认签到数据完整后，按流程结束签到并进行结课报备。
  • 在成绩管理中上传经核对的照片、视频和成绩。
  • 证书是否生成，先取得招生或对应负责人的明确通知。

成绩口径

  • 理论成绩来自考试结果。
  • 实操成绩来自工种实训小组评分，按小组成员逐人核对后填写。
  • 提交前核对姓名、身份证号、组别、理论成绩和实操成绩。

每周事项

  • 整理各区到场培训人数，并按期次保存明细。
  • 汇总指定区域的培训人数、项目数量和后续两周空缺名额，提交给对应负责人。
  • 完成当期工作简讯和内部汇报。
06

纸质档案归档

每期结课后及时装盒入柜，按以下顺序从上到下放置：

  1. 盒面封面：贴在档案盒外。
  2. 档案封面组：封面、手签、电子签到表、横版课表。
  3. 理论考试组：封面、已评分纸质试卷、横版电子成绩单、盖章成绩汇总表。
  4. 工种实训组：封面、工种实训考核表。
  5. 安全实训组：封面、安全实训考核表，按考号顺序排列并置于最后。
装订、曲别针和盖章要求以当前档案模板为准；入柜前检查期次、班级、日期和页序。
07

日常维护与协作

  • 定期检查反光衣、头盔、安全带、灭火器、扩音设备、电池和实训工具的数量与状态，异常及时报告。
  • 保持教室、实训工位、工具区和废料区整洁；实训结束落实工完场清。
  • 理论课按现场需要巡查课堂纪律；遇到难以处理的情况及时请讲师或负责人协助。
  • 控制课程节奏，发现时间超支或剩余过多时及时与讲师沟通。
  • 形成可追溯的工作记录：时间、事项、处理人、处理结果和需要跟进的问题。
